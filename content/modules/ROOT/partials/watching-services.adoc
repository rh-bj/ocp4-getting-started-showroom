[#{section-k8s}-kubectl-watch-services]
[.console-input]
[source,bash,subs="+macros,+attributes"]
----
oc get services
----

[.console-output]
[source,bash,subs="+macros,+attributes"]
----
NAME    TYPE        CLUSTER-IP       EXTERNAL-IP   PORT(S)    AGE
myapp   ClusterIP   172.231.21.155   <none>        8080/TCP   5s
----

``CLUSTER-IP``는 Service가 생성되는 즉시 할당되며, 이 주소로 클러스터 내부 어디서든 Service에 접근할 수 있습니다. 반면 ``EXTERNAL-IP``는 클러스터 밖에서 접근하기 위한 주소로, 실제 클라우드 로드밸런서와 연동되어야 채워집니다.
