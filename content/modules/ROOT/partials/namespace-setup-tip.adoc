[TIP]
====
실습을 부분적으로 진행한다면 ``{set-namespace}`` 프로젝트(네임스페이스)가 아직 존재하지 않을 수도 있습니다. 
다음 명령으로 해당 프로젝트가 존재하는지 확인하세요.

[.console-input]
[source, bash, subs="+attributes"]
----
oc get project {set-namespace}
----

응답이 다음과 같다면,

[.console-output]
[source,bash, subs="+attributes"]
----
Error from server (Forbidden): projects.project.openshift.io "{user}-{set-namespace}" is forbidden: User "{user}" cannot get resource "projects" in API group "project.openshift.io" in the namespace "{user}-{set-namespace}"
----

다음 명령으로 네임스페이스를 생성할 수 있습니다.

[.console-input]
[source, bash, subs="+attributes"]
----
oc new-project {set-namespace}
----
====
