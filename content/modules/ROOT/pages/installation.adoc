== 실습 환경 접속 정보

[IMPORTANT]
====
반드시 아래 정보를 사용해서 환경에 접속하세요!
====

여러분의 클러스터 접속 정보는 다음과 같습니다.

(아래 링크를 클릭하여 웹콘솔을 별도 창으로 띄워도 되고, 현재 보시는 화면 오른쪽에서 바로 사용해도 됩니다)

**웹 콘솔:** {openshift_console_url} +

image::console-login.png[console-login]

OpenShift의 웹 콘솔 화면을 보시면, 위와 같이 로그인 정보를 입력하게 되어 있습니다.

미리 주어진 아래의 유저이름(userX)과 비밀번호를 입력해서 로그인 하세요. 

아래 그림과 같이, 주황색 박스 오른쪽에 있는 노란색 문서 모양 아이콘을 클릭하면, 주황색 박스 안의 텍스트가 복사됩니다. 

image::copy-button.png[copy-button]

**사용자 이름:**
[.console-input]
[source,bash,subs="+macros,+attributes"]
----
{user}
----

**비밀번호:**
[.console-input]
[source,bash,subs="+macros,+attributes"]
----
{password}
----

위 정보를 사용해서 Openshift 웹 콘솔에 로그인한 뒤, 화면 오른쪽 위 [>_] 아이콘을 클릭하여 웹 터미널을 열 수 있습니다. 

image::2-1.png[2-1]

만약 [>_] 아이콘을 클릭했을 때 웹 터미널 화면이 바로 보이지 않는다면, 아래와 같이 적절한 네임스페이스를 선택하고 '시작'버튼을 눌러 터미널을 활성화해야 합니다. 

``wksp-{user}``를 선택한 뒤 '시작' 버튼을 누르세요.

image::2-3.png[2-3]

웹 터미널이 정상적으로 열렸다면, 연결이 잘 되어 있는지 다음 명령으로 확인해 봅시다.

[#whoami-check]
[.console-input]
[source,bash,subs="+macros,+attributes"]
----
oc whoami
oc project
----

[IMPORTANT]
====
복사한 텍스트를 웹터미널에 붙여넣을 때, 환경에 따라 붙여넣기 단축키가 다르게 작용할 수 있습니다. 
Windows 사용자라면 krb:[CTRL+SHIFT+v] 또는 krb:[Shift+Insert]를, Mac 사용자라면 krb:[command+v]를 눌러 텍스트를 붙여넣으세요.
====

``oc whoami``는 현재 로그인되어 있는 사용자를, ``oc project``는 명령을 실행했을 때 기본적으로 리소스가 생성될 네임스페이스(OpenShift에서는 이를 "프로젝트"라고도 부릅니다)를 보여줍니다. 아마 ``wksp-{user}``가 표시될 텐데, 이는 실습을 시작할 수 있도록 여러분만을 위해 미리 만들어 둔 프로젝트입니다.

두 명령 모두 오류 없이 사용자 이름과 프로젝트 이름을 보여준다면, 클러스터에 정상적으로 연결되어 있는 것이므로 다음 장으로 넘어갈 준비가 된 것입니다.
