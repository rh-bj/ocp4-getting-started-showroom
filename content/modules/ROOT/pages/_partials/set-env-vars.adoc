.환경 변수

[cols="4*^,4*."]
|===
|**변수** |**설명** |**기본값** | **예시**

|REGISTRY_USERNAME
|컨테이너 레지스트리 ``$REGISTRY_URL``에 인증할 때 사용할 컨테이너 레지스트리 사용자 ID
|
|demo

|REGISTRY_PASSWORD
|컨테이너 레지스트리 ``$REGISTRY_URL``에 인증할 때 사용할 컨테이너 레지스트리 사용자 비밀번호
|
|demopassword

|REGISTRY_URL
|컨테이너 레지스트리 URL이며, 기본값은 https://index.docker.io 입니다.
|https://index.docker.io
|https://quay.io/v2

|DESTINATION_IMAGE_NAME
|빌드할 이미지의 정규화된 전체 이름
|
| quay.io/foo/bar:v1.0
